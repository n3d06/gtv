# gotiengviet

Bộ gõ thuần Telex cho Windows 10/11, viết bằng C, exe 32 KB, chạy dưới khay hệ thống.

## Cài

Tải bản cài ở [Releases](https://github.com/n3d06/gtv/releases).

## Dùng

- `Ctrl+Shift` bật/tắt tiếng Việt (đổi được trong menu khay).
- Click phải icon khay: phím tắt, khởi động cùng Windows, quyền admin, danh sách app loại trừ.

## Build

```
build.bat
```

Cần Visual Studio Build Tools (MSVC). Có Inno Setup 6 thì build luôn bản cài.
